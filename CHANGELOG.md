# Changelog

## 1.1.0
- Numpad keys can now be bound: Numpad 0-9, Numpad Enter, +, -, *, / and the numpad period. They show as "Numpad 5", "Numpad +" and so on.
- Keep NumLock on when using numpad hotkeys; NumLock itself can't be bound.
- Mods that read their keys through Unity's key codes (all of ours) pick numpad binds up with no update of their own.

## 1.0.0
- First version: F11 menu listing every mod's BepInEx settings (switches, numbers, choices, text, hotkeys), an All keys page with clash highlighting, a startup clash notice, Default buttons, Re-read files.
- `set-required-items.ps1` marks Mod Menu as a Required item on our other Workshop mods.
